State at every event

See what every event changed

Open any event to see its payload and metadata, the aggregate state it resulted in, and exactly how that state differs from the one before.

  • Aggregate state after every event, versioned
  • Diff against the previous state, field by field
Commands and outcomes

Find out why a command failed

Every command is listed with its outcome. A rejected command shows the cause it failed with, and you can resubmit it straight from the console.

Trace

Follow a command to its events

Open a command to see exactly which events it produced, in the order they happened, and jump into any of them.

  • Events linked to the command that caused them
  • In the order they were produced
  • Open an event without losing your place
